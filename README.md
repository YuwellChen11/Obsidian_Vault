# Obsidian Vault

这是一个用于记录机械臂相关项目问题、调试过程和技术总结的 Obsidian 知识库。

当前内容主要围绕视觉识别、YOLO 部署、Jetson 环境问题、相机标定等项目实践展开。仓库中的笔记偏工程记录性质，适合用于复盘问题、迁移环境、整理实验流程和沉淀项目经验。

## 内容导航

| 路径 | 说明 |
| --- | --- |
| `Project/部署Yolov11.md` | YOLOv11 部署相关记录 |
| `Project/视觉识别说明.md` | 机械臂视觉识别方案、数据集、标注和联调说明 |
| `Project/Jetson重装系统后Firefox无法打开.md` | Jetson 重装系统后的 Firefox 启动问题记录 |
| `Project/Matlab标定USB摄像头（720p）.md` | 使用 Matlab 标定 USB 摄像头的流程和脚本记录 |
| `.obsidian/` | Obsidian 配置、插件和主题文件 |

## 阅读方式

可以直接在 GitHub 中浏览 Markdown 文件，也可以克隆到本地后用 Obsidian 打开：

```bash
git clone https://github.com/YuwellChen11/Obsidian_Vault.git
```

打开 Obsidian 后，选择克隆得到的 `Obsidian_Vault` 文件夹作为 vault 即可。

## 适用场景

- 机械臂项目过程问题记录
- 视觉识别和数据集整理
- Jetson / Ubuntu 环境部署排错
- 相机标定与实验流程复盘
- 项目经验沉淀和后续快速查阅
